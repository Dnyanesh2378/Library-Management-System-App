# Library Management System

A Python-based Library Management System built using Streamlit.

## Features

- User registration and login
- Email OTP verification
- Password-based authentication
- Library book management
- Mobile-friendly web access

## Technologies Used

- Python
- Streamlit
- SMTP / Gmail
- GitHub
- Streamlit Community Cloud

## Installation

1. Clone the repository:

   git clone YOUR_GITHUB_REPOSITORY_URL

2. Install dependencies:

   pip install -r requirements.txt

3. Configure your Streamlit secrets.

4. Run the application:

   streamlit run app.py

## Security

Keep email credentials and app passwords private. Never upload secrets.toml to a public GitHub repository.

## Purpose

This project was developed for learning Python and web application development.
